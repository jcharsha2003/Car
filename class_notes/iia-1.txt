The central philosophy of IIA

Integration is not merely joining data.

Integration is not merely resolving schemas.

Integration is not merely matching entities.

Integration is the process of constructing defensible knowledge from 
heterogeneous evidence.

The next generation of integration systems will be semantic, probabilistic, 
graph-based, multimodal, LLM-assisted, privacy-aware and decision-centric.

The final challenge: What should an intelligent integration system do 
when it does not know the answer?

Integration Approaches

• Materialized-based

• Extract → Transform → Load into DWH
• Best for governed BI, historical analytics and repeatable reporting

• Mediation-based: Virtual integration via federated queries
• Sources  Wrappers  Mediator  Federated Query
• Best for real-time access and autonomous source systems

• Hybrid: Semantic layer + materialized views

• Useful for enterprise semantic architectures

• Straight Through Processing: Rule-based/Learning-based
• Event  Rules/ML  Decision  Automated Action

• AI/ML-driven: Use embeddings for schema & entity mapping

• Embeddings  candidate generation  ML/LLM decision  validation

• Context-Oriented: Entity Discovery, enrichment and linkages

• Entity Discovery  Context collection  Enrichment  Linkage  Contextual view

How to compare integration approaches

Four design questions
• Where does integration happen?
• When does data become 
materialized?
• Where is semantic/identity 
reasoning performed?
• What happens when sources 
change or fail?

Central trade-off

• Latency vs freshness
• Coupling vs autonomy
• Control vs flexibility
• Engineering cost vs integration 
intelligence

No architecture is universally superior: the application determines the right integration strategy.

The recurring business-value framework

• Accuracy — Did we get the right answer?

• Completeness — Did we integrate the necessary evidence?

• Trust — Can we explain and defend the answer?

• Cost — Is the integration economically worthwhile?

• Decision value — Did integration improve an outcome?

Which of these five dimensions should dominate when they conflict?
